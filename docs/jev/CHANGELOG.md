# Jev 통합 변경 기록

## evidence-check 질문 정책 2 — 2026-09-19

- 실제 전송 질문·선택지와 참조 지침에서 INSUFFICIENT/CONTRADICTED의 차이를 명확히 했습니다. 기록 부재와 명시적 미실행, 린트·빌드와 테스트, 다른 버전의 근거를 구분합니다.
- 완료 보고를 수용할 수 있는지와 주장에 대한 반대 증거가 있는지를 분리했습니다. NOT_APPLICABLE은 명시된 검토 범위가 주장을 제외할 때만 사용합니다.
- 한국어·영어 28개 원본 사례를 각 조건에서 세 번 실행한 최종 비교에서 138/168 → 168/168 일치를 확인했습니다. 마지막에 추가한 8개 새 사례는 별도로 45/48 → 48/48이었습니다. 일반 정확도 보장이 아닌 합성 평가 결과이며, 1차 수정안의 남은 실패도 [검증 기록](EVIDENCE_CHECK_VALIDATION.md)에 보존합니다.
- 실행기 버전·기록 형식은 0.1.1을 유지합니다. 예제 policy.revision은 `synthetic-evidence-policy@2`입니다.

## 0.1.1 — 2026-09-19

- macOS의 `/tmp`·`/var` 시스템 별칭을 지원하면서 사용자 생성 symlink·감시 경로 이탈은 계속 거부합니다.
- 실제 전송 JSON의 후보 순서를 보존하고 전송 해시를 승인·receipt에 연결합니다. 0.1.0 실행 폴더는 읽기 전용으로 보존하며 자동 이관·재전송하지 않습니다.
- 공식 `jev-preview`·`jev-latest` 별칭과 Choice의 `null` 설명을 지원하고 고정 모델 일치 검사는 유지합니다.
- 참고용 jev-review 본문의 전사 오타를 원문과 대조해 복원하여 기존 해시 기록과 일치시켰습니다.
- delegated 실행 자격 검사와 advisory/evaluation 검사를 구분하고 이미 승인된 전송 범위를 재사용하도록 지침을 다듬었습니다.
- 재현된 결함의 회귀 검사와 API·모델 품질·에이전트 행동을 구분하는 평가 절차를 추가했습니다. 실제 실행 결과는 [TEST_REPORT.md](TEST_REPORT.md)에 기록합니다.

## 0.1.0 — 2026-09-19

- standalone 스킬 7개, 공통 Python CLI, 판단 절차 12개와 입력·합성 응답 예제를 추가했습니다.
- 위임(delegated), 검토 보조(advisory), 평가(evaluation)를 구분하고 외부 전송 미리보기·승인 해시·파일 상태 확인·원 응답 기록을 제공합니다.
- 저장소의 루트형 배치에 맞춘 비파괴 설치기와 오프라인 테스트 64개를 포함합니다.
- 외부 MIT 스킬 스냅숏과 출처 고지를 참고 문서로 분리했습니다.
- 실제 API 호출, 모델 판단 품질, macOS와 실제 Codex 새 세션 노출은 미검증입니다.
