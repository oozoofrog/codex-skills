# gptplease

**ChatGPT Chat·Work에 질문과 파일을 보내고, 목적·복잡도에 맞는 모델과 사고 수준을 적용한 뒤 완료 응답을 호출한 Codex 세션에서 처리하는 스킬**입니다. `gptwork`의 새 이름이며 기존 `gptpro`의 코드 상담 용도를 통합했습니다.

```text
$gptplease Work에서 이 JSON을 정리해 주세요. 모델과 사고 수준은 목적에 맞춰 고르고 결과를 가져와 주세요.
$gptplease Chat에서 이 설계를 깊이 검토하고 답변을 여기서 확인해주세요.
$gptplease Chat Pro로 선택한 파일의 버그를 검토해주세요.
$gptplease Work에서 Astra High로 이 기획안을 분석하고 완료 결과를 가져와 주세요.
```

| 요청 | 적용 기준 |
| --- | --- |
| Chat 지정 | Chat에서 목적·복잡도에 맞는 모델과 사고 수준 선택 |
| Chat Pro 지정 | Chat에서 Pro를 지원하는 적합한 모델 선택, Pro 필수 |
| Chat Astra Pro 지정 | Chat + GPT-6 Astra + Pro 모두 필수 |
| Work 지정 또는 새 요청에 모드 생략 | Work에서 목적·복잡도에 맞는 조합 선택 |
| 모델 또는 사고 수준만 지정 | 지정값을 지키고 나머지만 자동 선택 |
| 기존 대화의 후속 요청 | 해당 대화의 모드 유지, 이번 요청에 맞춰 전송 전 설정 확인 |
| 현재 설정 유지 / 추천만 요청 | 관측 설정 보존 / 설정 변경·전송 없이 추천 |
| 로컬 스킬 설명·편집 또는 초안만 요청 | 외부 전송 없음 |

기본 후보는 명확한 추출·변환 **Luna Light**, 일반 작업 **Terra Medium**, 본격적인 분석·검토 **Sol High**, 여러 단계·도구가 얽힌 어려운 작업 **Astra High 또는 Extra High**입니다. 모델과 사고 수준을 따로 판단하며 시간·비용 제한과 실제 선택기의 지원 조합을 우선합니다. 단순 후속 요청은 명시한 Astra에 Light를 적용할 수도 있습니다. 중요한 최종 판단에만 Max·Chat Pro를 선택적으로 고려하며, Ultra와 Fast/priority는 자동으로 켜지 않습니다. [모델·사고 수준 선택](references/model-selection.md)에 판단 기준과 한계를 정리했습니다.

자동 선택 후보가 없으면 같은 모드의 적합한 대안을 고르고 이유를 알립니다. **사용자가 명시한 조합이 없으면 전송을 보류**합니다. Chat의 Pro와 계정 배지, Work의 Max/Ultra는 구분합니다. Chat Astra Pro의 실제 가용성은 매번 확인하며, 2026-09-07 관측에서는 Chat 선택기에 Astra가 없어 해당 명시 조합은 보내지 않았습니다. [입력창 설정](references/composer-settings.md)을 참고하세요.

## 공통 실행

1. 관련 맥락·선택 파일·요청한 diff·완료 기준을 정리합니다.
2. 지원되는 브라우저에서 대상 대화와 Chat/Work를 확인하고 모델·사고 수준을 실제로 설정합니다.
3. 승인된 파일을 실제 업로드하고 첨부 완료를 확인합니다. 파일 경로나 본문 붙여넣기를 실제 첨부 성공으로 취급하지 않습니다.
4. 같은 입력창에서 설정·필수 첨부를 확인한 뒤 한 번 전송합니다.
5. 호출 세션에서 해당 요청의 최종 응답 완료를 기다리고 전체 내용을 회수합니다.
6. 현재 파일·테스트와 대조해 답변·검토 결과를 처리합니다. 수정까지 승인된 요청은 로컬 변경과 검증을 이어갑니다.

프로젝트를 지정하지 않으면 프로젝트 없는 대화를 사용합니다. 대기 중 진행 상황을 알리고 취소·기한을 따릅니다. 명시적으로 생성만 요청한 경우에만 수집을 생략합니다. 설정·첨부가 막히면 준비한 요청을 보존하며 불완전한 상태로 보내지 않습니다. 세부 기준은 [파일 첨부](references/file-attachments.md), [응답 회수](references/response-return.md), [요청 준비](references/task-handoff.md)에 있습니다.

## 대체 범위와 검증

전용 Runner, Launcher, Python/Node 상담 런타임 없이 지원되는 브라우저 제어와 ChatGPT 로그인을 사용합니다. 공개 범위와 최종 판단은 호출 세션이 책임집니다. 기존 `gptpro`의 자동 비밀정보 검사, 해시로 결속한 패키지 승인, 영구 재전송 차단, 서명 스트림·receipt·전용 복구 런타임은 포함하지 않습니다. 기존 패키지와 승인을 가져오거나 재개하지 않으며, 새 요청은 `$gptplease`로 시작합니다.

2026-09-07 확인한 실제 동작:

- Work Astra Light 새 요청과 Medium 후속 요청의 완료 응답 회수.
- 이전 대화를 복제하지 않은 새 세션에서 당시 설치된 `gptwork` 자동 노출, JSON 실제 첨부, 고유값·한국어 문장·계산 결과 대조, 회수 첨부의 바이트 일치.
- 과거 Sol Pro 경로의 `5.6 Pro` 전송 전 표시, Python 파일 실제 첨부, 결함 식별과 최소 수정안, 완료 응답 회수, 원본/회수 첨부 및 계산 결과 일치.

이는 해당 UI와 작은 파일 사례의 증거입니다. 새 이름의 설치 후 별도 app-server의 `skills/list` 강제 갱신으로 `gptplease:gptplease` 활성 노출과 이전 두 이름의 비노출도 확인했습니다. 서버 내부 모델 ID, 모든 파일 형식·크기, 중단 복구 전체는 별도 검증 대상입니다.

## 설치

Plugin은 `gptplease@codex-skills`, standalone은 `gptplease/`를 선택합니다. 설치 후 새 대화에서 `$gptplease`를 호출하세요. 이전 이름의 플러그인·스킬을 제거해 중복 노출을 피하고, 과거 상담 패키지와 로그인 프로필은 별도로 보존합니다. [저장소 설치 안내](https://github.com/oozoofrog/codex-skills/blob/main/docs/plugin-installation.md)를 참고하세요.
