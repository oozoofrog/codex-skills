# 오케스트레이터와 함께 쓰는 경우

일반 단일 세션에는 필요 없다. 리더/워커·특정 모델·추가 MCP를 새로 요구하지 않는다. 기존 오케스트레이터 상태와 이 task state가 함께 있을 때만 다음을 적용한다.

전체 작업의 복구 지점은 하나로 정한다. `.codex/work/<task-id>.md`가 전체 목표·완료 조건·검증·Exact Next Action을 관리한다면 오케스트레이터의 state에는 그 경로와 worker별 범위·의존성·반환 증거만 둔다. 기존 상태를 자동 이동·삭제하거나 같은 목표를 두 곳에서 계속 갱신하지 않는다. 오케스트레이터 단독 상태만 있는 작업을 요청 없이 초기화하지 않는다.

정책 선택과 필요한 실행 참조는 Established Decisions와 Current Technical State에 짧게 기록한다. 정책 이름은 권한이 아니다. 재개 시 원래 사용자 선택·현재 지시를 확인하고 Git/실제 파일·worker 생존과 마지막 관측 상태를 대조한다. 과거 모델·effort·worker ID를 현재 실행의 증거로 쓰지 않는다. 미확인 worker와의 쓰기 충돌을 해결하기 전 같은 범위를 다시 맡기지 않는다.

서로 다른 clone/worktree 사이에서 ignored state와 미커밋 파일이 자동 복제되지 않는다. state의 최신 시각으로 요구사항이나 권한의 정본을 결정하지 않는다. 긴 대화, 인증 정보, 원문 로그는 state에 넣지 않는다. 기존 템플릿에 오케스트레이션 전용 필드를 의무 추가하지 않는다.

이 연결은 모델 변경, 전역 config 수정, 세션 자동 생성·종료, 자동 commit/stash/reset/삭제/push를 제공하지 않는다. 전체 완료·durable 문서 승격·선택적 보관은 원래 session-continuity 절차를 따른다.
