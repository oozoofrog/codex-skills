# Human checkpoints

Pause for the account owner when visible ChatGPT app state cannot be proved: login, account/workspace, Developer Mode/App authorization, Chat/Pro/model selection, Accessibility permission, CAPTCHA/MFA, Send ambiguity, or incomplete response/copy.

Ask for one precise action at a time. Never ask the user to reveal passwords, MFA codes, cookies, tokens, Tunnel IDs, API keys, or unrelated conversations. Never use Browser, CDP, Electron internals, or private endpoints to bypass the checkpoint.

An attended click is not package approval or Send evidence. An ambiguous Send must preserve the existing Chat and prohibit resend.
