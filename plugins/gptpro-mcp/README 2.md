# GPT Pro MCP Plugin

This directory packages the optional top-level [`gptpro-mcp`](../../gptpro-mcp/) Skill as a skills-only Codex Plugin.

The canonical standalone Skill remains at `gptpro-mcp/`; `skills/gptpro-mcp/` is a deterministic distribution mirror. Install it only for explicitly selected advanced read-only repository exploration or legacy MCP lifecycle recovery.
