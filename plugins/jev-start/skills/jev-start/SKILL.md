# Jev Start

현재 작업에서 Jev를 활용할 맥락과 위임 기준을 설정한다. 사용자 변경 전까지 현재 작업에 적용하며, 매 턴 다시 읽거나 호출할 필요는 없다. 새 세션에 자동으로 계승되는 전역 설정은 아니다.

## 역할과 호출 가치

- **Codex**는 코드 작성·리팩터링·버그 분석·테스트 작성·API 조사·구현 방법 탐색과 전체 작업의 계획·통합을 맡는다.
- **Jev**는 제공된 상태·근거·기준 안에서 선택, 위험 평가, 요구사항 적합성, 주장과 증거의 일치 같은 의미 판단을 맡는다. 맥락이 충분하면 정책 선택과 검토 판정도 가능하다. 단순 키워드 분류로 용도를 제한하지 않는다.
- **코드**는 정확한 규칙·계산·임계값 비교·필수 검사·상태 결합·실행을 맡는다. `confidence >= threshold`는 코드로 계산한다.
- Jev는 typed 판단과 확률을 반환하는 결정 모델이다. 저장소 탐색·도구 실행·코드 생성·자유 서술 추론을 스스로 수행하는 별도 Codex 워커로 취급하지 않는다.
- 반복 판단·다수 후보·재사용 가능한 업무 분기에서 이득을 우선 찾는다. 단발성도 결과가 다음 행동을 실질적으로 바꿀 때는 사용한다. 이미 Codex가 해결한 판단을 같은 정보로 재확인하거나 형식적인 최종 승인 단계로 매번 호출하지 않는다.

## 맥락 전달과 결과 적용

1. **결정 계약을 정한다.** 어떤 행동을 바꿀 판단인지, 후보·필수 조건·우선순위·필요한 증거가 무엇인지 정한다. 검토·위험·정책·테스트·release 판정에는 [결정 위임 예시](references/decision-delegation.md)를 필요한 범위만 읽는다.
2. **필요한 상태를 전달한다.** Jev가 현재 대화·저장소·로컬 정책을 이미 안다고 가정하지 않는다. 사용자 목표, 관련 원문과 반대 증거, 실제 검사 결과와 미확인, 선택지와 기준을 전송할 `state` 또는 질문에 명시한다. Codex의 결론만 보내 동의를 구하지 않는다. 외부 전송은 허용된 범위 안에서 최소 자료로 한정한다.
3. **적절한 출력 형태로 호출한다.** 후보 하나는 Choice, 독립 조건의 참일 확률은 Noul, 정의된 수준에 따른 정도는 Score를 쓴다. 실제 API 호출에는 사용 가능한 `typesafe-ai` 스킬과 현재 문서를 참조한다. 스킬이 없으면 [공식 문서](https://docs.typesafe.ai/llms.txt)에서 관련 API·primitive만 확인한다. 기존 실행 코드를 재사용하고 필요한 경우에만 최소 코드를 만든다.
4. **불확실성과 실행을 구분한다.** 후보 없음·근거 부족이 가능한 질문에는 이를 표현할 결과를 둔다. 부족한 사용자 우선순위나 필수 증거를 confidence로 대신하지 않는다. 정책의 필수 조건을 먼저 적용하고 유효한 의미 판단은 정해진 분기에 반영한다. merge·배포 같은 실행에는 기존 권한과 필수 검사를 그대로 적용한다.
5. **전체 비용을 줄인다.** 같은 상태에 대한 독립 질문은 함께 보내고, 앞선 답에 의존하는 질문은 순차 처리한다. 근거·질문·기준·모델 버전이 같은 결과는 재사용한다. 배치 크기는 전송량과 실제 비용에 맞춘다. 서비스 오류·인증 부재·지원되지 않는 입력은 판단 결과로 바꾸지 말고 Codex로 돌아와 원래 작업을 계속한다.

Choice/Score의 confidence는 분포 집중도이며 정확성의 보증이 아니다. Noul에는 별도 confidence가 없다. 수치 임계값과 사용자 가치의 가중치는 코드·명시된 정책에 두고, 필수 조건 위반을 다른 점수로 상쇄하지 않는다. 미검증 임계값으로 중요한 작업의 자동 처리를 확대하지 않는다.

실제 사용했다면 맡긴 판단, 반영한 결과, 남은 불확실성을 짧게 보고한다. Jev가 생성하지 않는 자유 서술 근거를 만들어 붙이지 않는다. 호출하지 않은 매 턴마다 미사용 보고를 남기거나, 사용 기회를 만들려고 작업을 늘리지 않는다.

## 세션에서의 위치

`jev-start`는 선택적 맥락 진입점이다. `typesafe-ai`는 API·질문 설계 방법을, `jev-blender-use` 같은 작업 기능은 실제 실행을 제공한다. 이미 해당 기능에 필요한 계약이 있으면 `jev-start`를 추가로 읽을 필요가 없다. 매 세션의 필수 의존성·매 턴 hook·자동 승인기·별도 실행기를 만들지 않는다.
