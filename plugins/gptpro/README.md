# GPT Pro Collaborator Plugin

This directory packages the top-level [`gptpro`](../../gptpro/) v0.6 isolated Electron Runner and inline-snapshot collaboration Skill as a skills-only Codex Plugin. It runs only when the user explicitly requests `$gptpro` for plan, ask, review, debug, or architecture work; ordinary Codex work never triggers it.

The canonical standalone Skill remains at `gptpro/` so Codex's bundled `$skill-installer` and existing clone-based installations keep working. `skills/gptpro/` is a byte-and-mode exact distribution mirror. The package has no custom ChatGPT App, Browser, Computer Use, MCP, Secure MCP Tunnel, local-function, or server-tool dependency. Its optional `~/Applications/gptpro Launcher.app` starts a second installed ChatGPT process with a dedicated owner-only profile and port 9223, leaving the ordinary app untouched. The implementation collects one approved POST through its signed WebSocket handoff and, when a tool-role candidate or pre-handoff assistant/delta state makes branch provenance ambiguous, spends at most 30 seconds proving only that known current branch by GET. One approved canary passed logged-in signed completion, conditional branch proof, automatic import, and independent evaluation on Desktop `26.901.31953` on 2026-09-05. No standalone recovery was used; `collect-response` remains separate GET-only recovery that never resends. This does not prove reconnect/resume or general compatibility. Update both copies together; `scripts/tests/test_plugin_distribution.py` rejects drift.

Installation instructions live in [`docs/plugin-installation.md`](../../docs/plugin-installation.md).
