# Repo Tuist Map

TalkMediaKitUI 저장소에서 Tuist 관련 작업을 할 때 우선 확인할 파일 지도입니다.

## Root manifests

- `Tuist.swift`: Tuist project 설정과 local plugin 등록. 현재 `Tuist/Plugins/TalkPlugin`을 local plugin으로 사용합니다.
- `Workspace.swift`: `Talk.xcworkspace` 정의. `Projects/**`를 workspace project로 포함하고 autogenerated workspace schemes는 비활성화합니다.
- `Projects/<Module>/Project.swift`: 각 모듈의 target, dependency, scheme, test/sample app 선언 위치입니다.

## Module lifecycle owners

| 작업 | primary owner | 같이 확인할 파일 |
| --- | --- | --- |
| 모듈 추가 | `Projects/<Module>/Project.swift` | `Dependencies+Module.swift`, `Schemes/**`, `Targets/SampleApp/**`, `Targets/Tests/**` |
| 모듈 삭제 | 삭제 대상 `Project.swift`와 참조하는 `Projects/**/Project.swift` | `Dependencies+Module.swift`, sample/test helper, source `import`, resource/core data path |
| 모듈 이동 | old/new `Projects/<Module>` directory | `Dependencies+Module.swift` path, schemes, test plan path, source imports |
| 모듈 이름 변경 | `Project.swift`의 target/project/scheme 문자열 | `.Module.*` alias, `import <Module>`, bundle ID, test plan, sample app |
| target 속성 변경 | `Projects/<Module>/Project.swift` | `BuildSettings/**`, `Scripts/Scripts.swift`, common helper |
| 공통 패턴 변경 | `Tuist/Plugins/TalkPlugin/ProjectDescriptionHelpers/**` | 영향받는 모든 `Projects/**/Project.swift` |

## Shared project helper

- `Tuist/ProjectDescriptionHelpers/Project+Templates.swift`
  - `Project.project(...)` wrapper
  - `StaticFramework`, `DynamicFramework`, `AppItemModel`, `AppExtensionItemModel`, `XCTestItem`, `AggregateItemModel`을 실제 `Target`으로 변환
  - `BuildValidator`로 dependency rule을 검증
  - `resourceSynthesizers: []`를 명시해 resource synthesizer를 사용하지 않는 패턴

## TalkPlugin helper

- `Tuist/Plugins/TalkPlugin/ProjectDescriptionHelpers/Model/**`
  - `StaticFramework`, `DynamicFramework`, `XCTestItem` 등 target item 모델 정의
- `Tuist/Plugins/TalkPlugin/ProjectDescriptionHelpers/Dependencies/Dependencies+Module.swift`
  - 내부 모듈 dependency shortcut (`.Module.*`) 정의
- `Tuist/Plugins/TalkPlugin/ProjectDescriptionHelpers/Dependencies/Dependencies+SPM.swift`
  - SPM/external dependency shortcut 정의
- `Tuist/Plugins/TalkPlugin/ProjectDescriptionHelpers/BuildRules/BuildRules.swift`
  - dependency validation rule 정의
- `Tuist/Plugins/TalkPlugin/ProjectDescriptionHelpers/BuildSettings/**`
  - `SettingFactory`, `BuildSettings`, configuration별 build setting 정의
- `Tuist/Plugins/TalkPlugin/ProjectDescriptionHelpers/Schemes/**`
  - `SchemeFactory`, `generateDefaultScheme`, Talk app scheme 정의
- `Tuist/Plugins/TalkPlugin/ProjectDescriptionHelpers/Targets/**`
  - App extension, sample app, 일부 test/framework helper target 정의
- `Tuist/Plugins/TalkPlugin/ProjectDescriptionHelpers/Scripts/Scripts.swift`
  - `.swiftlint` 등 target script shortcut 정의
- `Tuist/Plugins/TalkPlugin/ProjectDescriptionHelpers/Utils/Environment.swift`
  - 환경/사용자 preference에 따른 scheme filtering 등 동작 확인 위치

## Templates and packages

- `Tuist/Templates/**`: `tuist scaffold` 계열 template. 새 모듈 생성 패턴을 바꿀 때만 수정합니다.
- `Tuist/Package.swift`: Tuist helper/plugin 빌드용 package 정의.
- `Tuist/Package.resolved`: lockfile. 의도 없이 삭제하거나 광범위하게 바꾸지 않습니다.
- `Tuist/LocalPackages/**`: local package 정의.
- `Tuist/Preferences/com.kakao.tuist.plist`: 기본 Tuist preference.
- `Tuist/Preferences/com.kakao.tuist.private.plist`: 개인 scheme preference. 보통 커밋 대상이 아닙니다.

## Scripts

- `Scripts/setup-env.sh`: mise/tuist/tuism 설치, 업데이트, doctor.
- `Scripts/tuist/tuism/install.sh`: 저장소 기준 tuism 설치 스크립트.
- `Scripts/addscheme/**`: 개인 Tuist preference에 scheme을 추가하는 보조 스크립트.
