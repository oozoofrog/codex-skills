# 합성 응답

모든 `*.response.json`은 실행기와 스킬 흐름 검사용으로 직접 만든 값이다. Jev API를 호출하여 얻은 응답이 아니다. 일반 Choice 예제는 첫 후보에 0.7을 주고, 근거 검토 예제는 누락된 실행 기록에 맞춰 INSUFFICIENT에 0.7을 준다. confidence는 설명용 0.4이며 이 관계를 실제 확신도 공식으로 해석하지 않는다. Score는 균등 분포, Noul은 설명용 0.8이다.

`eval-cases.json`은 집계기가 성공과 실패를 모두 세는지 확인하기 위해 의도적으로 2개 중 1개만 라벨에 맞도록 구성했다. 이 50%는 Jev 모델의 성능이 아니다.

## 근거 검토 예제

`evidence-check.response.json`의 INSUFFICIENT 응답은 테스트 실행 여부·결과 기록이 제공되지 않은 템플릿에 대응한다. 실행하지 않았다는 명시적 기록과 기록 부재를 구분한다. 이 응답은 합성 fixture이며 실제 모델 정확도를 입증하지 않는다.
