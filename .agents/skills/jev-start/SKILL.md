# Jev Start

현재 요청한 작업을 수행하면서 다음 기준을 적용한다. 사용자가 바꾸기 전까지 현재 작업에 유지한다.

- 반복 분류, 후보 관련성, 주장과 증거 대조처럼 좁은 의미 판단에서 추가 호출의 이득이 예상되면 Jev를 선택적으로 사용한다. 작은 단발성 판단과 정확한 규칙·계산·검색은 직접 처리한다.
- 실제 사용이 필요할 때 제공된 `typesafe-ai` 스킬을 읽고 현재 문서에 따라 호출한다. 기존 실행 코드를 재사용하고 필요한 경우에만 최소 코드를 만든다. 준비할 수 없는 의존성이나 인증 때문에 호출하지 못하면 그 한계를 밝히고 가능한 원래 작업을 계속한다.
- 허용된 외부 전송 범위에서 필요한 원문·현재 제약·판단 기준을 함께 전달한다. Jev가 이 대화나 저장소를 이미 안다고 가정하지 않는다. 독립된 질문은 가능한 범위에서 묶는다.
- 결과를 보조 판단으로 사용한다. 사용자 정책·권한, 필수 검사와 완료 조건은 그대로 적용한다. 이 스킬로 현재 모델·effort·컨텍스트 설정이 바뀌지는 않는다.
- 불확실하거나 증거와 충돌하는 결과는 원문과 도구로 재검토한다. 높은 confidence도 정확성을 보장하지 않는다. 서비스 실패·미실행을 모델의 판단 결과와 구분한다.
- 실제 사용했으면 무엇을 맡겼고 결과를 어떻게 반영했는지만 짧게 보고한다. Jev를 쓸 기회를 만들려고 원래 작업을 늘리지 않는다.
